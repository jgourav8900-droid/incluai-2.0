How INCLUAI 2.0 Operates

STEP 01
Unified Knowledge Ingestion

Approved HR handbooks, leave policies, and remote guidelines are indexed with vector embeddings.

STEP 02
Grounded Assistance & Tools

Employees query policies via Copilot, rewrite messages respectfully, and draft official emails with citations.

STEP 03
Confidential Feedback & Action

Physical or digital barriers are submitted with guaranteed anonymity, generating AI recommendations for HR.

Privacy, Anonymity & Multi-Tenant Security

Workplace reports handle sensitive employee information. INCLUAI enforces strict server-side safeguards.

✓ True Server-Side Anonymity
When Anonymous is selected, the server removes user ID, employee badge, IP, and tokens before persistence.
✓ Role-Based Access Control (RBAC)
Employees only see their own submitted reports. Only authorized HR administrators can review and resolve concerns.
